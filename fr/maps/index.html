Comment sont faites les cartes des régions de Cuvera

Dernière mise à jour : 4 novembre 2026

Les leçons Explorer de Cuvera comprennent six cartes simplifiées : Bordeaux, Napa Valley, Rioja, Bourgogne, Chablis et la Barossa Valley. Chaque carte est une image dessinée à partir de données géographiques ouvertes ; les noms de lieux sont ajoutés par l’application. Simplifiées pour apprendre, ce ne sont pas des cartes officielles ni des relevés, et elles n’impliquent aucune caution des producteurs des données.

Cette page décrit les données et la méthode, comme le demande la licence Open Database License (article 4.6) pour les cartes faites à partir des données d’OpenStreetMap. Cuvera ne publie pas les données intermédiaires.

Sources des données

  • Côtes, cours d’eau, surfaces en eau, villes et sommets (Bordeaux, Napa Valley, Rioja, Bourgogne, Barossa Valley) : © les contributeurs d’OpenStreetMap, données disponibles sous licence Open Database License (ODbL).
  • Aires d’appellation (Bourgogne, Chablis) : INAO, Délimitation parcellaire des AOC viticoles, mise à jour du 2 novembre 2026, Licence Ouverte 1.0.
  • Le Serein (Chablis) : IGN, BD TOPO® (tronçons hydrographiques du Serein, mise à jour du 21 août 2025), Licence Ouverte 2.0.
  • Limites de la Barossa Valley et de l’Eden Valley : Geographical Indications of Australia, © Wine Australia (édition 2022 v1, depuis remplacée), CC BY 4.0, simplifiées par Cuvera.
  • American Viticultural Areas (Napa Valley, utilisées seulement pour vérifier le placement des noms, non dessinées) : projet AVA de la bibliothèque de UC Davis, CC0.

Méthode

  1. Télécharger les données de chaque région avec les requêtes de fetch_<région>.sh : OpenStreetMap par l’API Overpass ; le fichier national de l’INAO sur data.gouv.fr (fetch_inao.sh) ; l’hydrographie de l’IGN par le service WFS de la Géoplateforme ; les régions de Wine Australia depuis leur publication en données ouvertes.
  2. Extraire les aires d’appellation du fichier de l’INAO (inao_extract.py) : filtre par appellation et par commune, conversion du Lambert-93 en latitude et longitude, simplification (Douglas–Peucker, de 8 à 60 m).
  3. Réduire le réseau hydrographique de l’IGN à une seule ligne (ign_mainline.py) : le plus court chemin dans le réseau principal coulant.
  4. Projeter chaque couche sur la grille propre à la carte, large de 340 unités, avec la formule linéaire de <région>.config.json : x = x0 + (lon − lon0) · kx, y = y0 + (lat0 − lat) · ky (build_map.py).
  5. Généraliser : enchaîner les tronçons de chaque cours d’eau en lignes continues, les simplifier (Douglas–Peucker, de 0,25 à 1,2 unité) et les lisser (deux passes de Chaikin) ; ne garder que les surfaces en eau des cours d’eau principaux ; écarter les bras secondaires courts ; fusionner les parcelles d’appellation en zones (dilatation puis érosion de 3 à 4 unités, bord adouci) ; masquer les quelques éléments trop petits pour être lus, listés dans chaque configuration.
  6. Dessiner l’image de base à quatre fois la grille (rendermap.swift, CoreGraphics sur macOS) : la mer est remplie à partir de points de départ, bornée par le trait de côte ; cours d’eau et teintes d’appellation sont dessinés dans la palette de Cuvera.

Les fichiers de configuration donnent chaque paramètre, filtre, point de départ et masque utilisé pour chaque carte. Suivre les étapes ci-dessus avec eux reproduit les images de base.

Pour l’exécuter

Prérequis : macOS avec les outils en ligne de commande de Xcode (pour swiftc), Python 3, curl et unzip. Placez les fichiers ci-dessous dans un même dossier, puis pour chaque région (ici Bordeaux)$ :

sh fetch_bordeaux.sh data
python3 build_map.py bordeaux.config.json data scene.json
swiftc -O rendermap.swift -o rendermap && ./rendermap scene.json bordeaux.png

Avec les données telles que publiées le 4 novembre 2026, ces étapes reproduisent exactement les images de base de Cuvera. OpenStreetMap est modifié en continu : un téléchargement ultérieur peut donner un résultat légèrement différent ; la configuration de la Napa Valley désigne aussi trois surfaces en eau d’OpenStreetMap par leur identifiant.

Fichiers

  • Scripts : build_map.py, rendermap.swift, inao_extract.py, ign_mainline.py
  • Téléchargements : Bordeaux, Napa Valley, Rioja, Bourgogne, Chablis, Barossa Valley, fichier de l’INAO
  • Configurations : Bordeaux, Napa Valley, Rioja, Bourgogne, Chablis, Barossa Valley
